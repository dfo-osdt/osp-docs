# Foire aux questions

## Formulaire de dossier de manuscrit {/* #manuscript-record-form */}

<details>
<summary>
### Comment puis-je ajouter ma publication si j’ai effectué mon examen de gestion du manuscrit à l’aide de l’ancien formulaire MRF? {/* #how-do-i-add-my-publication-if-i-completed-my-manuscript-management-review-using-the-old-form-mrf */}
</summary>

Consultez [Créer un nouveau dossier de publication publiée](./publications/create-publication-details-form#creating-a-record-for-an-existing-publication) si votre manuscrit a déjà été publié.

Consultez [Créer un nouveau dossier de publication acceptée](./publications/create-publication-details-form#creating-a-record-from-an-old-form-mrf-approval-prior-publication) si vous créez un dossier de publication pour une publication scientifique et technique secondaire de la DGEO aux fins de soumission à Publications scientifiques, ou si votre manuscrit n’a pas encore été publié par un éditeur.

</details>

<details>

<summary>
### J’ai créé mon formulaire de dossier de manuscrit avec le mauvais type de publication {/* #i-created-my-manuscript-record-form-with-the-wrong-publication-type */}

Consultez [Dupliquer un formulaire de dossier de manuscrit](./manuscript-record-forms/manuscript-record-form-features#duplicate-a-manuscript-record-form) pour dupliquer votre MRF avec le bon type de publication.

Consultez [Supprimer un formulaire de dossier de manuscrit](./manuscript-record-forms/manuscript-record-form-features#delete-a-manuscript-record-form) pour supprimer le MRF ayant le mauvais type de publication.

</details>

<details>

<summary>
### Je souhaite soumettre mon manuscrit sous deux types de publication différents {/* #i-want-to-submit-my-manuscript-as-two-different-publication-types */}
</summary>

Pour soumettre votre manuscrit sous deux types de publication différents, deux formulaires de dossier de manuscrit distincts doivent être créés. Les deux MRF doivent suivre le processus de publication.

Par exemple, si vous souhaitez soumettre votre manuscrit à un éditeur tiers et à un serveur de prépublication, vous devez créer un formulaire de dossier de manuscrit de type **Publication par un tiers** et un autre de type **Prépublication**. Chacun de ces MRF doit faire l’objet de son propre examen de gestion du manuscrit.

**Étapes**

1. Créez et remplissez le MRF du premier type de publication.
2. [Dupliquez le formulaire de dossier de manuscrit](./manuscript-record-forms/manuscript-record-form-features#duplicate-a-manuscript-record-form) et sélectionnez le deuxième type de publication.
3. Téléversez de nouveau le PDF du manuscrit dans le deuxième MRF.
4. Soumettez les deux MRF à l’examen de gestion du manuscrit.

**Résultat**

- Deux MRF de types de publication différents, mais contenant le même contenu, ont été créés.

</details>
