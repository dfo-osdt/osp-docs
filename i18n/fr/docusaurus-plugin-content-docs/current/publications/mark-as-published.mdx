# Marquer comme publié

**Étapes**

1. Cliquez sur **MARQUER COMME PUBLIÉ**.

**Résultat**

- L’état du formulaire de détails de publication est maintenant **Publié**.
- Le formulaire de détails de publication et la publication seront visibles dans l’[Explorateur de publications](../portal-basics/publication-explorer).

## Supprimer un formulaire de détails de publication {/* #delete-a-publication-details-form */}

Il peut arriver qu’un **dossier de publication** ait été créé, mais qu’il ne soit plus nécessaire dans le PSO. Par exemple, un dossier de publication en double peut avoir été créé alors qu’un seul dossier devrait être conservé dans le PSO.

**Étapes**

1. Cliquez sur **Supprimer la publication**.
2. Confirmez l’action.

**Résultat**

- Le formulaire de détails de publication a été supprimé du PSO.

**Informations supplémentaires**

- Un formulaire de détails de publication créé dans le cadre des [étapes communes du processus](../manuscript-record-forms/#common-process-steps) ne peut pas être supprimé.
- Vous devez être le créateur du formulaire ou avoir le rôle de rédacteur en chef pour supprimer un formulaire de détails de publication.
