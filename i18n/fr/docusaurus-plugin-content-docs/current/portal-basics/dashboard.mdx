# Tableau de bord

## Tableau de bord de l’auteur {/* #author-dashboard */}

La page **Tableau de bord** est le principal point d’accès du PSO et la page vers laquelle vous serez redirigé après une authentification réussie. Pour accéder à la page **Tableau de bord** à tout moment, sélectionnez le bouton **Tableau de bord** dans le menu situé à gauche. Consultez le **symbole carré** dans la figure **Tableau de bord**.

## Tableau de bord du rédacteur {/* #editor-dashboard */}

Si vous avez le [rôle de rédacteur régional ou de rédacteur en chef](../settings/user-profile#user-roles), vous pourrez consulter le tableau de bord du rédacteur. À partir de ce tableau de bord, vous pourrez consulter les publications scientifiques et techniques secondaires de la DGEO qui ont été soumises à Publications scientifiques aux fins d’examen et de publication.

### Boutons de navigation {/* #navigation-buttons-1 */}

- ○ Afficher mon tableau de bord
  - Ce bouton remplace le tableau de bord du rédacteur par celui de l’auteur. Un bouton situé au même endroit vous permet de revenir au tableau de bord du rédacteur.
- △ [Explorateur régional de manuscrits](./regional-manuscript-explorer)

### File d’attente des échéances {/* #due-queue */}

- **Titre** : Titre du rapport avec le numéro de catalogue attribué.
- **Personne-ressource** : Personne-ressource principale du rapport et région responsable.
- **Accepté le** : Date à laquelle le rapport a été soumis à Publications scientifiques.
- **Âge** : Nombre de jours écoulés depuis la soumission du rapport à Publications scientifiques.
- **Cahier** : Si le rapport a été signalé pendant l’[Examen de gestion du manuscrit](../manuscript-management-review/reviewing-manager-role) afin qu’il soit pris en considération pour le [Cahier de planification](../manuscript-management-review/submit-review#planning-binder), un drapeau rouge s’affichera.
