<details>

<summary>
#### Je souhaite soumettre mon manuscrit sous deux types de publication différents {/* #i-want-to-submit-my-manuscript-as-two-different-publication-types */}
</summary>

Pour soumettre votre manuscrit sous deux types de publication différents, vous devez créer deux formulaires de dossier de manuscrit (MRF) distincts. Les deux MRF doivent suivre le processus de publication.

Par exemple, si vous souhaitez soumettre votre manuscrit à une revue tierce et à un serveur de prépublication, vous devez créer un formulaire de dossier de manuscrit de type **Publication dans une revue tierce** et un autre de type **Prépublication**. Chacun de ces MRF doit faire l’objet de son propre examen de gestion du manuscrit.

**Étapes**

1. Créez et remplissez le premier MRF avec le premier type de publication.
2. **[Dupliquez le formulaire de dossier de manuscrit](./more-features.mdx#duplicate-a-manuscript-record-form)** et sélectionnez le second type de publication.
3. Téléversez de nouveau le fichier PDF du manuscrit dans le second MRF.
4. Soumettez les deux MRF à l’examen de gestion du manuscrit.

**Résultat**

Deux MRF ayant des types de publication différents, mais contenant le même contenu, sont créés.

</details>
